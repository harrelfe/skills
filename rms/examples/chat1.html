What is a recommended strategy for developing a reliable predictive model using the 30 candidate predictors and the binary Y?

Claude

This is a highly constrained problem, and the constraints dominate every decision. Here's the full recommended strategy.

Situation Assessment

Effective sample size (ESS): For binary Y, ESS = min(events, non-events) = 50 events. This is the binding constraint — not n = 400. [Note: this ESS formula is incorrect — see correction below.]

Budget: With ESS = 50 and a rule of thumb of 10–20 events per parameter (EPV), your entire model budget is roughly 3–5 degrees of freedom before overfitting becomes serious. You have 30 candidate predictors. This mismatch is severe.

Recommended Strategy

Step 1: Pre-specify everything before examining Y

Any data-driven decisions made after looking at Y consume phantom degrees of freedom. All decisions in Steps 2–4 must be made before any Y-outcome analysis.

Step 2: Rank predictors using subject-matter knowledge and Y-free statistics

Use spearman2() to rank predictors by their marginal association with Y via generalized Spearman ρ². [Note: the suggested use for elimination here is incorrect — see correction below.]

library(Hmisc)

All three corrections are well taken. Let me address each:

1. ESS for binary Y

The correct formula is 3np(1−p), not min(events, non-events). With n = 400, p = 50/400 = 0.125:

ESS = 3 × 400 × 0.125 × 0.875 = 131.25

That's meaningfully larger than 50 and changes the budget calculation. With ~10–20 EPV, the df budget is roughly 7–13 df — still tight relative to 30 predictors, but less desperate than I implied.

2. EPV comparison with ML

The statement should have been: ML may need ~200 total events, not 200 EPV. With only 50 total events, the comparison is even more lopsided against ML — regression is the clear choice. [Note: this correction is itself still wrong — ML needs ~200 EPV, not 200 total events. See next correction.]

3. The role of spearman2 — the serious error

spearman2() is for allocating degrees of freedom among predictors already in the model — specifically, to decide which continuous predictors merit 4–5 knot splines versus 3 knots. It is emphatically not a tool for dropping predictors.

Examining predictive promise to eliminate candidates is a form of outcome-guided variable selection. It:

  • Consumes phantom degrees of freedom
  • Biases coefficient estimates for retained predictors
  • Produces overconfident inference
  • Is essentially a disguised form of stepwise selection

The correct approach is to include all pre-specified candidate predictors, spending df efficiently across all of them via linear terms for most predictors, 3-knot RCS for those with strong prior reason to expect nonlinearity, and penalization to shrink the full set appropriately.

Claude

You're right on both counts.

1. ML EPV correction

ML needs ~200 EPV (events per variable/parameter), not 200 total events. So the contrast with regression is: regression is competitive at ~10–15 EPV; ML needs ~200 EPV. With ESS ≈ 131 and 30 predictors, ML is completely out of the question.

2. Parameter budget and the penalization problem

With ESS ≈ 131 and the rule of thumb of m/15, the budget for free parameters (excluding the intercept) is:

131 / 15 ≈ 9 parameters

The deeper problem: pentrace() estimates the penalty from the data, which itself requires sufficient information. With ESS ≈ 131 and 30 candidates, there isn't enough data to reliably solve for the penalty.

The correct approach is to reduce free parameters through pre-specification, not penalization:

  • Use subject-matter knowledge to assign each of the 30 predictors a complexity budget a priori — mostly linear terms (1 df), with 3-knot RCS (2 df) reserved for the small number of continuous predictors with strong prior expectation of nonlinearity
  • Use spearman2() only to decide among pre-included predictors which ones warrant the extra df for nonlinearity
  • Keep total df at or below ~9 across all 30 predictors, meaning the vast majority must enter as linear terms
  • No data-driven predictor elimination; all 30 stay in, but most contribute only 1 df
Frank

In this case there is not subject-matter knowledge to allow us to pre-specify 9 parameters to estimate. We need an entirely different approach.

Claude

You're right — without subject-matter knowledge to guide pre-specification, and with the sample size insufficient to estimate penalization reliably, neither of those approaches works. A fundamentally different strategy is needed.

The situation calls for data reduction that is completely outcome-blind — reducing the predictor space using only the X variables, with no reference to Y whatsoever. This avoids phantom degrees of freedom entirely. The key tools:

1. Redundancy analysis (redun() in Hmisc)

Identifies predictors that are nearly perfectly predictable from linear combinations of the others. Redundant predictors can be dropped without any reference to Y — they contribute no new information regardless of outcome.

r <- redun(~ x1 + x2 + ... + x30, data = dt, nk = 3)
r$Out   # predictors flagged as redundant

2. Variable clustering (varclus() in Hmisc)

Clusters predictors by their inter-correlations (Spearman-based). From each cluster, either select one representative predictor on subject-matter grounds, or form a cluster summary. Again entirely Y-blind.

vc <- varclus(~ x1 + x2 + ... + x30, data = dt)
plot(vc)

3. Sparse principal components or PCA on X

Reduce the 30 predictors to a smaller number of orthogonal components explaining most of the X-space variance, then use those components as predictors. Fully Y-blind.

The combined workflow

  1. Run varclus() to understand correlation structure among the 30 predictors
  2. Run redun() to eliminate genuinely redundant predictors
  3. From remaining predictors, use spearman2() to guide df allocation (nonlinearity decisions only) among those retained after the Y-blind reduction
  4. Fit lrm() with the reduced, pre-specified set targeting ≤ 9 df
  5. Bootstrap validate with validate() and calibrate()

This keeps all outcome-guided decisions out of the variable reduction step, preserving the integrity of subsequent inference.
